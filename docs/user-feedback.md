使用者指出：正視圖尚未帶入個人姿勢，動態感要更強；眨眼需要眼瞼、眼珠轉動需要獨立虹膜，

第三階段先交付重心／上身／頭部／髮絲的連動、既有 irides 圖層的受限位移、眨眼節奏控制，
以及保守的正視微轉頭提示。檢查顯示本次 irides Alpha 範圍為 66×16 px，訊號很弱；
眨眼暫時只隱藏眼白與虹膜，不能稱為已具備眼瞼。

下一個素材品質門檻：產生或人工補建左右眼瞼開／閉狀態、足夠不透明的左右虹膜與瞳孔、
眼白遮罩，以及頭部左右遮擋區的補繪。達成前不以正視縮放／透明度假稱完整眨眼或 3/4 轉頭。

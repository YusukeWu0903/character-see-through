## 2026-09-19：正視角色的動態與表情需求

使用者指出：正視圖尚未帶入個人姿勢，動態感要更強；眨眼需要眼瞼、眼珠轉動需要獨立虹膜，
也需要微左轉／微右轉，並要求依可行性逐步實現。

第三階段先交付重心／上身／頭部／髮絲的連動、既有 irides 圖層的受限位移、眨眼節奏控制，
以及保守的正視微轉頭提示。檢查顯示本次 irides Alpha 範圍為 66×16 px，訊號很弱；
眨眼暫時只隱藏眼白與虹膜，不能稱為已具備眼瞼。

下一個素材品質門檻：產生或人工補建左右眼瞼開／閉狀態、足夠不透明的左右虹膜與瞳孔、
眼白遮罩，以及頭部左右遮擋區的補繪。達成前不以正視縮放／透明度假稱完整眨眼或 3/4 轉頭。

## 2026-09-19：表情可讀性與女性化次級動作

使用者指出目前仍看不出眨眼，並要求將胸部起伏與彈性列為下一個女性化表現重點。

第四階段先量測左右眼的真實畫布中心，讓眼白與虹膜退場時，既有睫毛圖層收束到正確眼位，
形成可見的閉眼線。這是以現有素材驗證節奏的代理實作，不等同有美術品質的上下眼瞼。
胸部只在 `topwear`／`neck` 的胸口帶內，受呼吸與重心的低幅、延遲彈簧驅動；不提供獨立高幅度擺動，
以免與肩頸、衣物輪廓脫節或造成不自然的物理感。

下一個放行條件：由原始角色素材建立左右開眼／閉眼眼瞼與足夠的虹膜遮罩；並在人工作畫中確認
胸口帶的變形沒有拉扯衣物接縫。通過前只能稱為「閉眼線與保守次級動作」，不能稱為完整 Live2D 級眨眼。

## 2026-09-19：獨立眼瞼層的第一版

使用者確認要繼續，並要求不能遺漏胸部彈性。已建立 `eyelid_closed_left/right` 的獨立圖層契約：
每層是全畫布 RGBA、只含單眼的閉眼線，並會在眨眼時取代淡出的眼白與虹膜。
本次初始素材由既有左右睫毛 Alpha 壓縮而成，目的是先驗證正確位置、畫序、Alpha 與可替換管線；
它不是宣稱已完成的生成式眼瞼美術。產生的不符 Eris 筆觸的生成草稿未被加入專案。

胸口彈簧現改為由呼吸、重心與上身側彎共同驅動，帶阻尼延遲回彈；仍限制在服裝胸口帶，避免
形成與肩頸或衣物脫節的高幅度擺動。

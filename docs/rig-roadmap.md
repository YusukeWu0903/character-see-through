# 角色動態系統規格 v0.1

日期：2026-09-19。狀態：第二階段實作；視覺品質待使用者驗收。

## 目標與版本邊界

讓不熟悉 Spine／Live2D 的使用者用少量姿勢控制得到協調動作。
現有 `deab315` 標記為 `milestone/clean-layers-v1`；開發分支
`codex/hierarchical-rig-v1`。`/preview` 保留原動畫；`/preview-rig` 提供第一階段；
`/preview-deform` 提供第二階段。
PNG、PSD 和上游推論不變。Git 不含輸出素材，標籤不能恢復被刪除的素材；
原始成果仍保留於隔離任務資料夾，正式發布前須另做素材備份。

## 研究依據與設計決策

- [Spine 骨骼](https://esotericsoftware.com/spine-bones)：父節點變換傳給子節點。
  採用完整父變換，再疊加局部動作，避免用任意百分比削弱附著關係。
- [Live2D 父子階層](https://docs.live2d.com/en/cubism-editor-manual/system-of-parent-child-relation/)：
  用共同父變形器協調部件；本階段只實作剛性 2D 變換，尚非網格變形。
- [Spine 變換約束](https://esotericsoftware.com/spine-transform-constraints)：
  區分局部／世界座標、偏移及混合。未來可加局部可調權重，第一版父繼承固定完整。
- [Spine 權重](https://esotericsoftware.com/spine-weights)：網格頂點可受多骨骼影響；
  第二階段用於頸、肩、腰的連續過渡。
- [Spine IK](https://esotericsoftware.com/spine-ik-constraints)：以目標約束肢體末端；
  腳掌固定與肢體彎曲列後續階段，第一版不宣稱腳底鎖定。

以上參考設計概念，未複製商用 SDK 或宣稱相容其專有專案格式。

## 已知問題

舊 viewer 每層獨立呼吸相位與視差係數，造成五官相對位移。
語義圖層可能合併左右肢體，不能直接當成左右手腳各自旋轉。
原圖嘴部接縫／缺損屬於素材問題；rig 只能避免運動額外造成的錯位。

## 第一階段：共同驅動（本次）

輸入為全畫布 RGBA；画序沿用里程碑 viewer。rig 與畫序分離。
座標以畫布中心為原點、半邊長為 1、Y 向上；樞紐是靜止畫布座標。
子節點以 `父變換 × 繞靜止樞紐的局部變換` 求得世界變換。

```
root
└─ body（整體傾斜及同相位起伏）
   ├─ torso：topwear / neck / handwear
   │  └─ head：face / mouth / nose / eyes / ears / headwear
   │     ├─ frontHair：fronthair
   │     └─ backHair：backhair
   └─ legs：bottomwear / legwear / footwear
```

身體傾斜上限 ±1.5°、頭部侧傾 ±2°；這是平面側傾，非左右轉頭。
髮擺為受限局部角度，完整繼承頭部後添加週期擺動；不是物理模擬。
呼吸先用同相位整體微位移代理，不宣稱胸腔變形或腳掌固定。
五官共用同一矩陣；鞋與腿共用同一矩陣。零輸入必須精確回到原位。
介面提供四個姿勢控制、暫停、回原位、恢復預設及舊版入口。
預設啟用待機側傾與滑鼠跟隨，可分別關閉；四個滑桿設定基礎姿勢與起伏／髮擺幅度。
自動側傾疊加後仍受既有角度上限限制，回原位關閉自動動作，恢復預設重新啟用。
可選雲端／本機同步姿勢，或同一本機素材舊動作／新動作對照。
舊動作對照使用原預設幅度及滑鼠視差；姿勢條只控制新動作。

`viewer/eris-rig.json` schemaVersion=1 描述：

| 欄位 | 語義 |
|---|---|
| nodes[].id / parent | 唯一識別與父節點；唯一根的 parent 為 null |
| pivot | 靜止畫布 [x,y]，旋轉錨點 |
| motion | none / body / head / hair，姿勢驅動類型 |
| maxDegrees / phase | 局部角度上限與髮擺相位（弧度） |
| bindings | 語義圖層名稱到節點的對應，不決定畫序 |

限制：Eris 全身構圖專用手動錨點；其他角色不能宣稱自動綁定。
拒絕循環、缺失父節點、非法數值及未知 schema；未映射圖層顯示錯誤。
靜態 Canvas 2D 原型避免新增外部渲染依賴；尚無深度、網格或完整物理。

### 驗收

1. 原頁面與推論程式無改動，素材不被寫入。
2. 自動驗證零姿勢恆等、父子旋轉組合、樞紐固定、臉／嘴一致、腿／鞋一致。
3. 最小／最大參數、不同時間下驗證限制、有限值與可重現性。
4. 新頁成功載入 15 個雲端與 17 個本機素材；畫序不隨階層改動。
5. 人工比較頭、嘴、頸、肩、腰、腳與髮根；數學測試通過不等於視覺驗收通過。
6. 獨立入口待使用者接受後才升為預設。

### 第三階段：姿勢與表情（進行中）

正視角色能在不新增素材的情況下可靠完成：重心轉移、上身反向側彎、頭部微點頭、
髮絲延遲、既有虹膜的保守位移、眨眼節奏與最多約 7% 的頭部水平壓縮提示。
它們適合作為正面待機／對話動作。

「真正眨眼」需要開／閉眼瞼素材；「真正左右轉頭」需要左右眼、耳、鼻、嘴、髮絲與臉側的
遮擋補繪。這些是素材與生成品質任務，不能由變形器替代。下一個實作應先建立可驗收的眼部
素材包，再接入眼白裁切、獨立左右瞳孔與臉部轉向。

網格前先處理合併左右肢體；無充分遮擋補繪的素材需提示動作受限。
每階段獨立提交，通過測試與人工檢查才標記新的品質里程碑。
不得以降低 Alpha 品質換取動作。比較固定素材、同一時刻／姿勢及背景。
原品質版可透過舊入口立即使用；需要恢復程式時另建里程碑 worktree，避免 hard reset。
尚未驗收分支不合併 main；本次不自動公開推送實驗內容。

## 開發與驗證

`node --test tests/test_rig.mjs` 驗證核心變換契約。
`python -m pytest tests/test_seethrough_alpha.py -q` 驗證既有 Alpha／PSD 回歸。
獨立測試服務：`python -m uvicorn main:app --host 127.0.0.1 --port 8011`。
開啟 `/preview-rig?local=<task>`；8010 上的現有服務可持續使用。

第二階段入口：`/preview-deform?local=<task>`。目前提供 4° 上身側彎與 6° 頭部側傾，
可切換上半身放大；在同一姿勢下左側剛性、右側柔性，以辨識頸、肩、腰的接合差異。
`viewer/deform.html` 可點選校正樞紐、保存、匯出或匯入 JSON；設定與任務名稱綁定。
